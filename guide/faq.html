常见问题

如何添加新页面？

在 content/ 对应分类目录下创建 .md 文件，运行 bun run main.ts 重新构建即可。

如何修改主题？

  1. 在 themes/ 下创建新的主题目录
  2. 复制 default 主题的文件作为基础
  3. 修改 HTML 模板和 CSS 样式
  4. 在 site.config.ts 中将 theme 改为新主题名称

支持热更新吗？

当前版本需要在修改内容后手动重新运行构建命令。未来可以添加文件监听功能。

如何处理中文文件名？

建议使用英文文件名（会作为 URL slug），通过 Frontmatter 的 title 字段指定中文标题。

文章排序规则是什么？

文章默认按 date 字段倒序排列（最新的在前）。没有设置日期的文章排在最后。相同日期的文章按标题字母顺序排列。
