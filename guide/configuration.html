配置指南

站点配置通过 site.config.ts 文件进行管理。

基本配置

import type { SiteConfig } from "./src/types";

const config: SiteConfig = {
  title: "My Docs",
  description: "一个静态文档站点",
  theme: "default",
  pagination: {
    perPage: 10,
  },
};

export default config;

配置项说明

title

站点标题，会显示在浏览器标签页和首页。

description

站点描述，显示在首页标题下方。

theme

使用的主题名称，对应 themes/ 目录下的主题文件夹。

当前内置主题：default

pagination.perPage

每页显示的文章数量，默认值为 10。
